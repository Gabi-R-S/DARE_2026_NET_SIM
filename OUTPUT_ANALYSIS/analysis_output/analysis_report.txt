Interpretation notes
--------------------
Each input record is one run; the input contains no repeated trials for a configuration, so these comparisons do not estimate run-to-run variability or statistical significance.
Parameter effects compare each scenario only with the baseline having the same topology and routing mode. Execution-time percentage changes are included only when both runs complete; the C# metric remains zero when a run does not complete. Messages-after-close changes are absolute counts.
Scenario tags identify the setting variant (for example, low/high); the JSON does not include the numeric setting values.
