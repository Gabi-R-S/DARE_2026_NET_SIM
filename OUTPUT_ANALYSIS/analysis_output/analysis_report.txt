Interpretation notes
--------------------
Each input record is one run; the input contains no repeated trials for a configuration, so these comparisons do not estimate run-to-run variability or statistical significance.
Parameter effects compare each scenario only with the baseline having the same topology and routing mode. Execution-time percentage changes are included only when both runs complete; the C# metric remains zero when a run does not complete. Messages-after-close changes are absolute counts.
Network-delay profiles vary minimum and maximum delay together for random and scale-free topologies. Complete, ring, and star topologies use the minimum as their fixed communication delay; their maximum setting is not consumed by those network constructors.
The network-factorial response curves and effects average across all other crossed factor levels; one-factor parameter variations compare directly with the shared baseline. Spearman coefficients in parameter_trends.csv are descriptive rank trends across the available marginal setting means, with no p-values, confidence intervals, or causal claims.
Scenario tags identify each setting level. Numeric node-count and edge-probability tags encode their value; network-delay tags encode the minimum and maximum delay. The analysis extracts those values from the tags.
